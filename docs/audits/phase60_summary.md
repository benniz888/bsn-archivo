**Code-level observations to test in PHASE_62 (not verified as failures):** (1) the fallback `includes(v)` returns the FIRST substring match, which may be a different player than the one intended, and then fails `sol` membership; (2) `norm` removes `'`, `"`, `.` but not hyphens, commas, "Jr." suffixes, or inner nicknames (e.g. "Mario «Quijote» Morales" vs "Mario Morales" normalize differently, the documented PHASE_36 case); (3) accepted answers compare `p.n` strings and `used` tracks `p.n`, so duplicate names in POOL (POOL, POOL_2026, POOL_RGM, POOL_BSN26, POOL_PATCH merge) would collide; (4) attribute predicates depend on `p.t` tags and `p.pos`/`p.hi` presence, so players missing those fields never match. The exhaustive test in the PHASE_62 prompt will say which of these actually occur.
