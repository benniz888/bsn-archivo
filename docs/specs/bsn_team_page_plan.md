## 3. Anecdotes (from bsn_records.csv)
- Bayamón: 5 straight titles, 1971–1975 dynasty
- 1969 Bayamón–Río Piedras game: 17,621 attendance, still the BSN record
- Caciques de Humacao: 130 pts / 46 in a quarter (2012) — note: Humacao not in current franchises list, flag for archive team to confirm status
- Quebradillas: the Dalmau–Rivera "Dynamic Duo" 1966–69, sparked the 1970s dynasty (4 titles)
- Mets de Guaynabo: originally founded 1935 as Cangrejeros de Santurce, relocated to Guaynabo 1976 — the modern Cangrejeros are a separate, later-founded team
- Osos de Manatí: only active franchise with 0 titles — youngest team in the league, built-in underdog arc

## 4. Page layout (top → bottom)
1. **Masthead** — franchise name, city, founding year, status (from `bsn_franchises.csv`)
2. **Coliseo strip** — venue name, nickname if any, opened year, capacity (table above)
3. **Rivalry card** — top rival by finals-meeting count, meeting total, most recent meeting season, link to rival's page
4. **Anecdote block** — one sourced historical note per team (dynasty run, record game, relocation story, or "no title yet" for Manatí)
5. Existing stat tables, unchanged
