# PHASE_60 audit: controls under 44px (backlog)

Measured live on https://bsnarchivo.com (HEAD 8dce212) with Chromium 1193 via playwright-core, `getBoundingClientRect()` on every visible `a[href], button, input, select, textarea, summary, [role=tab], [role=button], [tabindex>=0]` after `networkidle` + 1.5 s. A control is listed if width OR height < 44 CSS px. **Scope limit: only the landing view of each of the six routes, at 390 and 1000 px. Sub-views, open menus, tables' inner controls, game states and the player page were not exercised**, so this list is a floor, not the full backlog. Unique per (selector, size) within a page.

Note: `.bottombar` tabs (phone nav) were not flagged (they measure >= 44px). `header.top` is `display:none` at 1000px (rail layout), so `.mark`, `#clubPill` etc. flag only at 390 there; `button.raillogo` (32x32) is the 1000px equivalent.
